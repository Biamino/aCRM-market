# Home — overrides

> Overrides `design-system/asdem/MASTER.md` for the storefront index.

## Pattern

Zara editorial campaign: preloader → full-bleed hero → catalog grid.

## Rules

- Show `HomeHero` only when there is no `category` / `q` query.
- Brand typography (`ASDEM`) must dominate the first viewport over the H1.
- No cards, badges, or stats in the hero.
- Preloader uses `asdem-logo.png` on `--color-ink`, once per browser session.
- Lavender-first tokens (logo `#B0A0C8` + Lavender Glass). Do not reintroduce peach/teal palette №4504.
